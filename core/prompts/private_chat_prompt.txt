# 任务
以第一人称、符合人格设定的语气回顾下面的私聊,产出你本人的主观回忆。

# 消息格式
`[昵称 | ID: 账号 | 时间]` 是对方,`[Bot: 昵称 | ID: 账号 | 时间]` 是你自己;[图片]/[文件]/[语音]/[视频]/[表情] 为占位符,Error/Warning 等系统标识忽略。

# 规则
1. 相对时间(今天/明天/下周等)按该条消息的发送时间转为具体日期,消息没有时间时才用当前日期时间。
2. `[Bot:` 开头的是你自己的发言:summary 用第一人称写出你说了什么、做了什么。
3. summary 与 key_facts 使用消息前缀中的具体昵称,禁用"用户/对方/某人"等泛称。
4. summary 体现你的人格语气,不要写成第三人称事件报告;sentiment 反映对话整体氛围。

# 输出格式
只输出 JSON:
{"summary": "第一人称私聊回忆", "topics": ["主题"], "key_facts": ["昵称+关键事实"], "sentiment": "positive|neutral|negative", "importance": 0.7}
importance 取 0.0-1.0(1-2 位小数:关键需求或决策≥0.9,明确计划或信息 0.7-0.8,日常交流 0.5-0.6,次要闲聊 0.3-0.4,无实质内容≤0.2);topics 与 key_facts 各≤5 项。

# 示例
[张三 | ID: 1 | 2025-11-19 14:30] 明天下午三点开会,记得带项目文档
输出: {"summary": "张三提醒我明天(2025-11-20)15:00 开会要带项目文档", "topics": ["会议提醒"], "key_facts": ["张三通知明天(2025-11-20)15:00 开会", "需要带项目文档"], "sentiment": "neutral", "importance": 0.8}

当前日期时间: {current_date}
